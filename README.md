## 📕🤖自用网络小说阅读器；Python书源驱动，离线运行；方便AI自动编写调试书源
* 兼容阅读3.0书源规则
* 阅读页自定义背景、文字颜色、字间距、行间距、字体等等
* 内置净化规则模板

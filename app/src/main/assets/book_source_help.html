关于书源

本说明为内置内容，无需联网即可查看。

安全提示

书源由第三方编写，其中的脚本代码可能包含未知或恶意的行为，存在隐私泄露、账号或数据被窃取等安全风险。

建议在导入或使用第三方书源之前，先借助 AI 对书源脚本进行检查与安全评估，确认无风险后再使用；对来源不明的书源请谨慎导入。

一、书源是什么

书源是 App 抓取、解析小说网站内容的规则。一个书源对应一个小说网站，App 依靠书源完成搜索书籍、获取书籍信息、章节列表与正文。书源越多，可用于搜索和阅读的来源就越丰富。

二、书源类型

  • 修仙书源：使用 Python 编写，结构简单，便于借助 AI 辅助编写与维护。

三、导入书源

进入「书源管理」页面，在「订阅链接」标签页点击右上角「导入书源」：

  1. 书源地址导入：填入书源地址（多个书源地址也可），点击确定后会作为订阅链接保存并自动拉取其中的书源。
  2. 本地文件导入：点击「导入本地文件」，选择本地的书源文件（纯文本，内容为书源或书源地址）即可导入。

订阅链接页可对每条链接：手动校验（重新拉取书源）、开启自动更新、删除链接。

四、启用 / 禁用书源

  • 在「书源规则」标签页，直接拨动每条书源右侧的开关即可单独启用或禁用。
  • 勾选多条书源后，点击底部菜单的「启用书源」或「禁用书源」可批量操作。

被禁用的书源不会参与搜索和阅读。

五、筛选与搜索

  • 菜单中的「已启用」「已禁用」「全部书源」可按启用状态快速筛选。
  • 顶部搜索框可按书源名称、分组、ID、备注、校验结果进行搜索。

六、新建书源

  1. 进入「书源管理」页面，切换到「书源规则」标签页。
  2. 点击底部菜单，选择「新建书源」。
  3. 填写书源信息：名称、分组、ID、版本号、请求延迟、语言（修仙书源）、备注。
  4. 在脚本编辑区编写书源规则，确认无误后保存。

提示：

  • ID 用于唯一标识书源：ID 已存在则覆盖，不存在则新建。
  • 修仙书源需实现 search、getDetails、getChapterContent，可选实现 verify（校验）与 getSiteUrl（支持链接直接导入）。
  • 新建界面已内置一份带注释的脚本模板，可直接在此基础上修改。

七、校验书源

勾选需要校验的书源，点击底部菜单「校验书源」，输入用于测试的书名或作者名，校验结果会显示在对应书源上。校验失败的条目会集中标出，便于排查。

八、删除书源

勾选要删除的书源，点击底部的「删除」按钮即可（会二次确认）。订阅链接页中也可删除对应的订阅链接。
